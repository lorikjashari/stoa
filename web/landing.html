The problem

On site, an answer has to be right — not just sound right.

Miscounts symbols

Doors, fixtures and schedule rows are read as pictures and estimated — not counted from geometry.

Misreads scales

A room area is only right when the drawing's units and scale are parsed correctly — not guessed.

Invents dimensions

A plausible number with nothing on the sheet to back it up. In construction that's a liability.

How it works

Cheapest trustworthy
engine first.

Each question routes to the first engine that can answer it exactly. An LLM is only used where the drawing has no structure to compute from.

1A

Geometry / BIM

CAD and IFC drawings answered by spatial index. Polygons on the sheet, elements in 3D.

1B

Detection hybrid

Counts on raster plans via a detection network. Zero tokens at question time for evaluated plans.

Query planner
