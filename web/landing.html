Why OQVAR / compute, don’t guess

An answer that only sounds right is useless on site.

Site engineers spend hours a day searching dense drawing sets. General-purpose AI reads those drawings as pictures, and it shows. Same sheet, two answers:

General-purpose AI

Illustration

“There are about 9 doors on this floor.”

  • Miscounts symbols. Doors and fixtures are estimated from pixels.
  • Misreads scales. An area is only right if the scale is.
  • Invents dimensions. A plausible number with nothing behind it.

How it answers / cheapest trustworthy engine first

Exact when it can be. Honest when it can’t.

Each question goes to the first engine that can answer it exactly. A language model steps in only where the drawing has no structure to compute from, and the answer always says which engine answered.
